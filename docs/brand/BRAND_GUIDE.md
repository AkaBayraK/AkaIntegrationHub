# Aka Integration Hub — Marka Kılavuzu

**Ad:** Aka Integration Hub · **Kısa ad:** AIH · **Slogan:** Connect · Notify · Automate / Bağlan · Bildir · Otomatikleştir

## Logo
Özgün "A-akış" işareti: yükselen iki kol bir "A" oluşturur, ortadaki dalgalı turkuaz çizgi veri akışını ve bağlantıyı
temsil eder. `BRAND_CONCEPT.png` yalnızca ilham kaynağıdır; buradaki vektörler sıfırdan çizilmiştir.

| Dosya | Kullanım |
|---|---|
| [logo-mark.svg](assets/logo-mark.svg) | Renkli işaret (gradient) |
| [logo-mark-mono.svg](assets/logo-mark-mono.svg) | Tek renk, `currentColor` ile boyanır |
| [logo-light.svg](assets/logo-light.svg) | İşaret + yazı, açık zemin |
| [logo-dark.svg](assets/logo-dark.svg) | İşaret + yazı, koyu zemin |
| [favicon.svg](assets/favicon.svg) | Favicon / uygulama ikonu |

Koruma alanı: işaret yüksekliğinin %25'i. En küçük boyut: işaret 16 px, yazılı logo 120 px genişlik.
Logo döndürülmez, gölge/efekt eklenmez, renkleri değiştirilmez (mono varyant hariç).

## Renkler
| Token | Değer | Kullanım |
|---|---|---|
| `--aih-color-brand-navy` | `#0B1B3F` | Metin, koyu zemin |
| `--aih-color-brand-blue` | `#2563EB` | Birincil eylem |
| `--aih-color-brand-violet` | `#7C3AED` | Vurgu, odak halkası |
| `--aih-color-brand-turquoise` | `#06B6D4` | Akış, bağlantı |
| `--aih-color-brand-green` | `#10B981` | Başarı |

Light/dark tema değerleri ve aralık/radius token'ları: `packages/design-tokens/tokens.json`.
Host uygulamalar `--aih-*` değişkenlerini kendi temalarıyla ezebilir.

## Tipografi
Sistem font yığını (ek font lisansı gerekmez). Inter/Poppins kullanılmak istenirse OFL-1.1 lisansı envantere eklenmelidir.

## Hukuki not
Marka adı, logo ve alan adının tescil uygunluğu araştırılmamıştır (risk R-01).
