# Documentation & Developer Portal

## Hedef
Aka Integration Hub için TR/EN, sürümlenmiş ve geliştirici dostu dokümantasyon.

## Bilgi mimarisi
- Getting Started: SaaS, self-hosted, Docker, ilk tenant ve proje
- SystemAdmin: provider, SMS/SMTP, kontör, şablon, rota, kota, log
- Developer: OpenAPI 3.1, Swagger UI, webhook, auth, idempotency
- SDK: Java/Spring Boot, .NET/ASP.NET Core, TypeScript
- Embed UI: Next.js React, tema, locale, auth, izinler, Storybook
- Architecture: C4/Mermaid, ADR, data model, sequence, threat model
- Operations: cache, queue, backup/restore, alert, SLO, runbook
- Compliance: OSS SBOM/NOTICE, KVKK/GDPR değerlendirme, veri saklama

## Kalite kapısı
CI'da broken-link, OpenAPI schema lint, örnek kod build/test, sürüm uyumu, TR/EN içerik kontrolü. Her fazda docs ve changelog güncelle.
